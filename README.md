# Харнес тимлида: скилл оценки задачи перед автоматизацией

Скилл для Claude Code к воркшопу «Пишем свой harness тимлида» (Podlodka Teamlead Crew, октябрь 2026).

Вы описываете рутину, которую хотите отдать агенту. Скилл сначала задаёт уточняющие вопросы, потом заполняет карточку кейса и выносит вердикт: пока не автоматизировать, скрипт, воркфлоу с моделью или агент. В конце - минимальный старт на неделю.

Главный вопрос, с которого начинается интервью: кто и что сделает с результатом. Если ответа нет, вердикт - пока не автоматизировать.

## Установка

В Claude Code:

```
/plugin marketplace add crazyfrogspb/teamlead-harness-skill
/plugin install automation-review@teamlead-harness
```

Обновление: `/plugin marketplace update teamlead-harness`.

## Как пользоваться

Опишите задачу как коллеге: «хочу агента, который каждую пятницу собирает статус по проектам из Jira и чата». Скилл подхватится сам, или вызовите его явно: `/automation-review`.

Дальше агент задаёт вопросы по одному. На «не знаю» он пишет в карточке «неизвестно» и идёт дальше, поэтому отвечать на всё не обязательно.

## Что в карточке

- **Зачем:** проблема, целевое действие, цена.
- **Как устроено:** факты, контекст и память, процедура, формат результата, границы и риски, сбои, схема шагов с исполнителями `[код]` / `[модель]` / `[человек]`.
- **Как внедрять:** офлайн-проверка, владелец, чью работу меняем, как умрёт через месяц, дата и признак пересмотра.

## ТЗ для агента-разработчика

Если вердикт - скрипт, воркфлоу или агент, скилл предложит собрать ТЗ в `automation-cards/<имя>-spec.md`: цель, вход, шаги с исполнителями, контракт результата, права, сбои, приёмка, первый этап, открытые вопросы. Стек и системы, которых вы не называли, скилл не выбирает - они уходят в открытые вопросы.

## Без агента

`template.md` - те же вопросы и карточка для заполнения руками или вместе с командой.

## Эвалы

В `evals/` шесть кейсов. Каждый прогоняется со скиллом и без него, чтобы было видно, что скилл добавляет сверх модели:

```
claude plugin eval . --no-publish
```

| Кейс | Со скиллом | Без скилла |
|---|---|---|
| Сначала спрашивает, а не выносит вердикт | 5/6 | 0/6 |
| Нет целевого действия - не автоматизировать | 3/3 | 0/3 |
| Учитывает людей, чью работу меняет | 3/3 | 0/3 |
| Отдаёт расчёты коду | 3/3 | 3/3 |
| Видит, что хватит скрипта | 3/3 | 3/3 |
| Ограничивает запись | 3/3 | 3/3 |

Последние три модель делает и без скилла. Они остаются как проверка, что скилл это не сломал.
